# 跨卷腾空间、收尾与零复制交付

本页导出通用方法与教训，没有导出现场跨卷调度器、服务密钥、共享清单或最终核查程序。需要代码适配时先固定输入/状态协议，在隔离测试目录完成中断与冲突验证。

## 跨卷搬运

目标是空间腾挪而非仅提升解密速度：整份读取源文件 → 解密受支持段、直传明文段 → 写另一卷临时文件 → 持久化 → **完整目标读回并比较 SHA256** → 不覆盖安装 → 记录结果并持久化 → 再核对源身份、删除源。未加密文件也要完整搬运和读回；只比较文件大小/头部不够。重名不同、源变化、读回失败均留源并报告，重新启动先核对已有目标和日志，不能重复删源。

1. 先决定最终共享布局和目标保留量；同一共享最终应放在一个卷上，避免分成两半后权限、备份和服务入口难维护。
2. 有独立授权后，在源卷内改名隔离整个待搬目录，记录原名/实际源/目标/状态，确保原位控制器不再扫描它。只改配置里的名字不能证明已隔离；不要把旧路径消失解释成搬空。改名和切换需协调已运行任务。
3. 按实际设备/卷身份绑定，限制复制、读回、队列和每批删源量；源密文 footer、完成记录和 key 继续独立备份。原位流程与搬运对同一文件不得并发。
4. 完整读写再读回在满负荷 RAID 上很慢。限制 MB/s 是上限，不是实际速度，不能用配置速率估完工时间。小文件、随机 IO 和集中 unlink 可能压低原位速度；先记录基线，必要时缩批。
5. 已删源逻辑字节、卷即时净释放和原位增占分别计量；其他引用/事务/同时写入会使它们不同。搬运结束后的回收站仍可能含密文，须纳入收尾。

## 最终只读核查与例外

待控制器结束且队列排空后，按每个共享列出剩余密文，分类为未入范围、格式/marker 不支持、文件头未知、同名冲突、链接/特殊文件和 IO/状态错误；另外列回收站、遗留临时文件及勒索说明。只读核对目标类型/长度和日志只是存在性核查，不能冒充完整 SHA 或历史原件认证。

核查不要按 @/# 前缀排除。明确每次排除的精确系统/工具目录及搬运实际源。设置时间/文件上限的烟测必须标记“不完整”和遗漏范围。扫描期间状态变化、坏日志、权限错误均保留未知；`root-done` 不是全量成功。最终输出注明采集时间、范围、日志来源、剩余数量与每类处理责任。

例外先完整备份密文并读回 SHA，再在独立目录生成旁路明文副本并完整读回；保留当前同名文件，不放宽全局格式规则去强行通过。检查 JPEG/视频容器/数据库等实际结构；数据库与 WAL/SHM 成组保留，不能覆盖活动库。零头字节不是零长度，无法识别不等于解密失败或可用。临时文件、回收站及勒索说明只列清单；清理需要另行明确范围。

## 零复制的只读交付

用干净电脑上的 Web 文件前端映射 NAS 受限只读 SFTP 适配器。这里“零复制”指不再建立一套业务数据副本；下载仍经过 NAS、适配器和前端的网络读写，不是内核零拷贝。恢复出的明文与未加密原件自动出现在完整目录中，不以只有解密输出的目录充当完整交付。

- NAS 保持物理隔离，不开放公网；只允许干净中转机的明确来源地址连接受限密钥。SSH 禁 shell、PTY、转发，适配器拒写且只能访问指定根，防路径穿越、符号链接越界和真实路径逃逸。
- SFTP 适配器和 Web 两层都过滤密文后缀（如 `*.L0CK3D`）、inplace/搬运临时文件、工具状态目录；原子安装后才可见。密文隐藏不能代替缺项报告。
- 每个用户仅 list/download，禁止上传、删除、改名和跨组访问；管理接口只在回环。公网只到干净电脑的 TLS 前端，不直接路由到 NAS。凭据放秘密管理；不导出旧服务配置和密钥。
- 为所有下载设置总限速，单连接限速无法限制多账号/多连接合计。把恢复 IO 优先级和管理响应也纳入观察，不因下载便利耗尽恢复资源。
- 内网和公网分别登录、列目录、下载真实样本、比 SHA/长度，同时验证写入拒绝、越界拒绝、密文/临时文件隐藏和管理端口不可达。登录页 200 不证明业务下载可用。

该方案适合逐步交付，不能证明 NAS 已清洁或替代独立备份。系统重建须按 [REBUILD.md](REBUILD.md) 单独实施。
